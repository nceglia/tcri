## 0.13.0 (2026-09-16)

### Breaking changes

- tcri now requires Python 3.12 or newer, and no longer supports 3.10 or 3.11. ([#143](https://github.com/nceglia/tcri/pull/143))
- tcri now requires anndata 0.12, scanpy 1.10, scikit-learn 1.6 or newer. ([#144](https://github.com/nceglia/tcri/pull/144))

### Features

- Stored tl results record the tool and the tcri version that wrote them, and a result from a newer tcri now raises a clear error instead of loading wrongly. ([#145](https://github.com/nceglia/tcri/pull/145))
- New Stored results page in the documentation listing what every tl function writes into adata.uns. ([#149](https://github.com/nceglia/tcri/pull/149))
- Saved sessions record their format version, and a session written by a newer tcri is refused with a clear message. ([#151](https://github.com/nceglia/tcri/pull/151))
