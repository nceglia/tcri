## 0.14.0 (2026-10-14)

### Breaking changes

- Early stopping moves to `train()` under scvi's names: `early_stopping_patience` (300) and new `early_stopping_min_delta` (0). `kl_weight_max` is `max_kl_weight`. Ignored arguments now raise. ([#207](https://github.com/nceglia/tcri/pull/207))
- `train(num_particles=...)` sets how many draws each ELBO step averages (default 1, as before). `use_enumeration` is removed; it never changed a fit. ([#210](https://github.com/nceglia/tcri/pull/210))
- `train(n_epochs_kl_warmup=150)` replaces `n_steps_kl_warmup`: the KL warmup is counted in epochs, like patience and `max_epochs`, whatever the dataset size or batch size. ([#220](https://github.com/nceglia/tcri/pull/220))
- `excess` is now `adjusted` in every stored result and is the quantity `stats` tests and `pl` draws by default; `quantity="value"` draws the raw value with its null. ([#221](https://github.com/nceglia/tcri/pull/221))
- `train()` defaults to `max_epochs=10000` (was 2000), so on small datasets the stopping rule, not the cap, ends a fit. ([#230](https://github.com/nceglia/tcri/pull/230))
- `setup_anndata` raises on cells without a clonotype: NaN or None, an empty or whitespace-only string, or `"nan"`. `TCRIModel()` raises on a clonotype, phenotype or covariate removed after setup. ([#231](https://github.com/nceglia/tcri/pull/231))
- `pp.pool_rare_clones` replaces `pp.group_singletons`: a clone with fewer than `min_cells` cells (default 3), all from one sample, is pooled into one `pooled@{group}` label per group. ([#236](https://github.com/nceglia/tcri/pull/236))
- Every model has a name, generated when `name=` is not given, and a load restores only that model and its nulls. Models saved without `name=` by earlier releases have to be refit. ([#238](https://github.com/nceglia/tcri/pull/238))
- `ut.auc_and_label_permutation` and `ut.bootstrap_auc` are removed; nothing in tcri used them. ([#239](https://github.com/nceglia/tcri/pull/239))
- Every tool leaves out the `pooled@{group}` pools of `pp.pool_rare_clones` by default (`exclude_pools=True`), which changes values on pooled data. ([#243](https://github.com/nceglia/tcri/pull/243))
- `pp.from_mudata` takes an explicit `clonotype_key` and `covariate_key`, read from either modality or `mdata.obs`; it drops cells without a clonotype and needs raw counts in `counts_layer`. ([#250](https://github.com/nceglia/tcri/pull/250))
- `TCRIModel(local_scale=...)` defaults to 10 (was 3), holding each covariate level closer to its clone's overall distribution; every fit that uses the default changes. ([#252](https://github.com/nceglia/tcri/pull/252))
- `pl` metric twins draw x in category order (`order=` overrides) and color replicate dots by replicate; every twin wraps long y labels and takes `legend=False` to draw no legend. ([#254](https://github.com/nceglia/tcri/pull/254))
- Scored metrics pair each draw with the null's own: `adjusted` is per draw in `table` and has `adjusted_sd`/`adjusted_hdi_*` in `result`; the null draws from its own seed; `pl` draws adjusted violins. ([#258](https://github.com/nceglia/tcri/pull/258))
- `train()` ends no fit within 2,000 optimizer steps of the end of the KL ramp, so small-data fits with few steps per epoch can run longer; fits with many steps per epoch stop as before. ([#259](https://github.com/nceglia/tcri/pull/259))
- `pp.clonotype_sharing` returns the group in a column named after `groupby`, with `All` as a value; `pp.pool_rare_clones` refuses a `key_added` of `groupby` or `samples` and a kept id `pooled@{group}`. ([#260](https://github.com/nceglia/tcri/pull/260))
- Reusing a `name=` already in the Pyro store and training on more than one device both raise; each null fit has its own namespace; a loaded model continues the KL ramp. ([#261](https://github.com/nceglia/tcri/pull/261))

### Features

- `pp.repertoire_summary` reports cells, clones, singleton clones and the largest clone per group and covariate level, read before fitting; on a pooled column, pools are counted apart from clones. ([#240](https://github.com/nceglia/tcri/pull/240))
- `pp.clone_persistence` counts, per group, the clones seen at both `cov_from` and `cov_to`, the clones flux and both deltas are computed on, and those seen at one level only. ([#241](https://github.com/nceglia/tcri/pull/241))
- `pp.clonotype_sharing` reports how clonotypes are shared across groups before fitting, per group or per shared clonotype; a derived clonotype column is measured on its source column. ([#242](https://github.com/nceglia/tcri/pull/242))

### Bug fixes

- datasets.simulate_from_fit_params runs: its phenotype label space comes from `omega`, so generating synthetic data from a real fit works. ([#203](https://github.com/nceglia/tcri/pull/203))
- A null rebuilt after loading a session onto a GPU keeps all its tensors on the GPU, so `perturb.gene_importance` runs instead of failing with a device mismatch. ([#214](https://github.com/nceglia/tcri/pull/214))
- `diag.loss` draws the validation objective on its own panel, labeled per cell, and marks the selected epoch; it no longer shares an axis with the summed training loss. ([#215](https://github.com/nceglia/tcri/pull/215))
- `save_tcri_session` records the registered replicate in `setup.json`, and `load_tcri_session` passes it to `setup_anndata`. ([#227](https://github.com/nceglia/tcri/pull/227))
- `tl.phenotypic_flux` accepts `distance_metric="kl"` (the default), `"dkl"` or `"l1"`; `"jsd"` and `"js"` raise, since flux is defined as the KL divergence. ([#249](https://github.com/nceglia/tcri/pull/249))
- Fixes `to_anndata` on h5ad objects with several fits, nulls after `TCRIModel.load`, `diag.loss` on a rebuilt null and its y range, and string clonotypes from `pp.clone_persistence`. ([#251](https://github.com/nceglia/tcri/pull/251))
- `training_record_['warmup_epochs_taken']` counts only the KL-warmup epochs, at most `n_epochs_kl_warmup`, instead of every epoch the fit trained. ([#256](https://github.com/nceglia/tcri/pull/256))
- `setup_anndata` no longer shows scvi's fewer-than-3-cells warning for the clonotype and per-cell `indices` columns; the phenotype, covariate and batch columns still warn. ([#263](https://github.com/nceglia/tcri/pull/263))
